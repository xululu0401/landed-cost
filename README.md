# 到岸成本台（landed-cost）

进口货物的到岸成本不是「货值 × 税率」：**运费和保险费也要计入完税价格**，**消费税是价内税**，
**增值税又按含关税与消费税的价格计征**。本页把这条链条逐层算清：这批货到岸一共多少钱、
税占了多大比例、每一行各交多少税、在这个卖价与毛利下最多能承受多高的货值、关税最多能涨到多少。

- 在线体验：https://xululu0401.github.io/landed-cost/
- 单文件交付：`index.html`（内联 `core.js` 与 `ui.js`，无外部依赖、不联网）
- 测试：`node --test tests/core.test.cjs`
- 构建：`node build.cjs`（由 `template.html` + `core.js` + `ui.js` 生成 `index.html`）

核心口径：完税价格 = 货值 + 国际运费 + 保险费（运保费按货值比例分摊）；
关税 = 完税价格 × 关税率；消费税（价内税）= (完税价格 + 关税) ÷ (1 − 消费税率) × 消费税率；
增值税 = (完税价格 + 关税 + 消费税) × 增值税率。综合税负率 = 税费 ÷ 完税价格；
含税放大倍数 = 1 + 综合税负率（完税价格每多 1 元，总成本多这么多元）。

反推是精确解：总成本对货值（以及统一关税率）是一次关系，用两点求值定出直线再解出上限，并把解回代重算核对残差。

边界：不查税则、不做商品归类、不联网；不处理从量税与复合计税、反倾销税、出口退税与进项抵扣、
免税额度与行邮税、跨境电商综合税优惠口径；不做申报口径的取整；不支持一行一币种与分批到货；
不给任何避税、低报或归类规避建议。默认样例与 5 个内置场景均为**虚构示例**，税率由用户自填。

口径与假设见页面内「算法与使用边界」，与 `../需求与调研.md` 一致。
